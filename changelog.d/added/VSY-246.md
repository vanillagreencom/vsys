- Home shows a Test leftovers line under the agent count: the stale test worlds, failed transient units and old test processes the optional agent warden last counted. A count the warden could not take reads not available, never zero, and the line says when there is no warden status, when it cannot be read, or how long ago the warden stopped writing it. On a narrow terminal the line wraps between counts rather than cutting one off. vsys finds the status where the warden writes it, under `/run/user/UID` when the session sets no `XDG_RUNTIME_DIR`, so a cron job or a `sudo -u` shell reads it too. The `vsys --once` snapshot carries the same counts under `leftovers`, with null for each one not read.
