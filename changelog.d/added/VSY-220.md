- Home raises a card when a system service averages a quarter of a CPU core or more for an hour, such as a service stuck in a loop. The card names the service, its hour average and the command that restarts it, and the Timeline records one alert for each time this happens. Containers and mounts under the system slice are not reported. A service is judged only when vsys holds a reading of it from 60 to 75 minutes ago. Until any service has one, as in `vsys --once --summary`, the summary lists `service-cpu` with a null level. Set the threshold with `serviceCpuPercent`.
