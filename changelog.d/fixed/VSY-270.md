- Go to terminal opens the default terminal through xdg-terminal-exec when vsys runs outside the agent's tmux server, without reporting a later window close as a failed launch. If xdg-terminal-exec is absent, it explains and copies the attach command. The copied command also works from a plain terminal. An agent whose tmux server has stopped, including one whose server's process id now belongs to another process, gets no terminal, no command and no pane read, because its pane handle may now name another pane.
